# Бот записи в студию красоты

Telegram-бот для записи клиентов в вымышленную студию красоты «Лотос».
Клиент выбирает услугу, дату и время прямо в Telegram, а бот сохраняет запись,
не даёт занять одно время дважды и напоминает о визите за сутки.

Бот: [@zapis_already_bot](https://t.me/zapis_already_bot)

&nbsp;&nbsp;&nbsp;&nbsp;Бот учебный и отвечает, только когда запущен.

Учебный проект для портфолио.

## Возможности

**Для клиента**
- Пошаговая запись: услуга, дата, время, подтверждение
- Показываются только свободные часы
- «Мои записи»: список будущих записей с кнопкой отмены
- Автоматическое напоминание за 24 часа до визита

**Хранение данных**
- Все записи сохраняются в базе данных SQLite и не пропадают после перезапуска
- База сама не даёт записать двух клиентов на одно и то же время
- Отменённые записи сразу освобождают время для других

**Для владельца студии**
- Команда `/admin` показывает все записи на выбранный день
- Доступ только у Telegram ID из списка в `.env` (владелец, сотрудники)

## Технологии

- Python 3.14
- [aiogram 3](https://docs.aiogram.dev/) для работы с Telegram Bot API
- FSM (машина состояний) для пошагового диалога записи
- SQLite для хранения записей, защита от двойной записи через `UNIQUE (date, time)`
- asyncio для фоновой задачи с напоминаниями

## Структура проекта

| Файл | За что отвечает |
|---|---|
| `bot.py` | запуск бота, `/start`, `/help`, `/myid`, «О студии» |
| `config.py` | чтение токена и списка админов из `.env` |
| `keyboards.py` | кнопки и клавиатуры |
| `booking.py` | пошаговая запись (FSM) |
| `my_bookings.py` | просмотр и отмена своих записей |
| `admin.py` | режим владельца |
| `reminders.py` | напоминания о визите |
| `database.py` | работа с базой SQLite |

## Запуск (Windows)

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Склонируй репозиторий и перейди в папку проекта.
3. Создай виртуальное окружение и установи зависимости:
   ```
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
4. Скопируй `.env.example` в `.env` и впиши свои значения:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=111111111,222222222
   ```
   Свой Telegram ID можно узнать, отправив боту команду `/myid`.
5. Запусти бота:
   ```
   .\.venv\Scripts\python.exe bot.py
   ```

## Безопасность

- Токен хранится только в `.env`, который не попадает в репозиторий (`.gitignore`).
- Бот хранит минимум данных: Telegram ID, имя и саму запись.
- Отменить можно только свою запись: база проверяет `user_id`.
